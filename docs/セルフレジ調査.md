# ドン・キホーテ セルフレジ 操作フロー調査

調査日: 2026-11-03 / 出典は末尾

対象は**フルセルフレジ**（客が自分で商品をスキャンして支払う型）。
ドン・キホーテには別に「セミセルフレジ」（店員が商品登録し、客は支払いだけ精算機で行う）と
「ピピットセルフ」（スマホで自分でスキャンしていく型）があるが、本アプリはフルセルフレジを再現する。

## 画面遷移（確定版）

| # | 画面 | 表示・ボタン |
|---|---|---|
| 1 | トップ画面 | 「有料レジ袋」「マイバッグ」「袋不要（お買上シール）」を選択。画面下に「チャージ」「残高照会」もある |
| 2 | 袋の確定 | 有料レジ袋 → サイズ（S 4円 / L 6円）と枚数。マイバッグ → 袋をフックに掛けて「次へ」 |
| 3 | majica確認 | 「majicaをお持ちですか？」→「はい」「いいえ」 |
| 4 | majicaスキャン | 「はい」の場合、**レジ左横のハンディスキャナ**でカード裏面バーコードを読み取る（アプリならアプリのバーコード） |
| 5 | 残高確認 | majicaマネー残高とポイント残高が表示され「確認」 |
| 6 | 商品スキャン | 商品のバーコードをスキャナにかざす。バーコードなしの商品は画面左のボタン（「やさい」「くだもの」「おさかな」「有料レジ袋」「その他」）から種類と個数を選ぶ。レジ袋は途中でも追加できる |
| 7 | お会計 | すべてスキャンしたら「お会計」をタップ |
| 8 | 支払いへ | majica残高が再表示され「お支払いへ」をタップ |
| 9 | 支払い方法選択 | 下記の選択肢から選ぶ |
| 10 | 支払い実行 | 現金は精算機に投入（**硬貨は一度に20枚まで**）。ポイント払いは利用ポイントを入力し、全額ポイントなら「はい」で会計終了 |
| 11 | 完了 | おつり・レシート（領収証も選べる） |

## 支払い方法

- 現金
- クレジットカード（**1回払いのみ**）
- majica（マネー払い / チャージ）
- ポイント払（**1ポイント = 1円**、1円単位で使える）
- 電子マネー（交通系IC、楽天Edy、iD、QUICPay）
- 商品券・クーポン券

### 注意点・制約

- **majicaマネーと現金の併用は不可**。ただしmajica残高不足のときは、その場でチャージするか、不足分を別の方法で払う案内が出る
- majica発券機で出したクーポン券は、セルフレジでは店員を呼んで割引してもらう必要がある
- **チャージ**はトップ画面から。majicaバーコードを読み取り →「マジカ払/チャージ」→「majicaチャージ」→ 金額を選んで紙幣を投入

## 出典間で食い違っていた点

| 論点 | 状況 |
|---|---|
| 最初の画面 | 多数の出典が「レジ袋の選択が先、majica確認は次」。一部Q&Aに「1番最初の画面がmajicaカードの確認」とする記述があり、**機種・店舗・時期で順番が違う可能性がある**。本アプリは多数派（レジ袋 → majica）を採用 |
| PayPay等のQRコード決済 | 「使えない」とする出典と「使える」とする出典の両方あり。**店舗・時期による**と判断し、本アプリでは選択肢に入れていない |

アピタ・ピアゴ（UDリテール／ユニー系）の店舗でも majica は全売場で利用可能で、
交通系IC・楽天Edy・iD・QUICPay に対応。レジの画面構成はドン・キホーテ系と同系統。
